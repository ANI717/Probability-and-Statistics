# Pictographs

A **pictograph** represents data using pictures or symbols.

Example:

🍎 = 5 apples

If a graph contains:

🍎 🍎 🍎

then:

3 × 5 = 15 apples

## Partial Symbols

A partial symbol represents part of the value.

If:

🍎 = 10

then:

½ 🍎 = 5

## Reading a Pictograph

1. Read the key.
2. Count the symbols.
3. Multiply by the value represented by each symbol.

## Example

Key:

⭐ = 4 students

Group A:

⭐⭐⭐⭐⭐

Number of students:

5 × 4 = 20

## Important

Never assume one symbol represents one observation.

Always check the **key/legend** first.
