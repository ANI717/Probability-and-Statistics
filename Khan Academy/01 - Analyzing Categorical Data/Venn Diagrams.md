# Venn Diagrams

A **Venn diagram** represents groups using overlapping circles.

It is useful for visualizing relationships between categories.

## Example

Suppose:

- A = people who like coffee
- B = people who like tea

The overlapping region represents people who like **both coffee and tea**.

## Regions

### A only

Belongs to A but not B.

### B only

Belongs to B but not A.

### Intersection

Belongs to both A and B.

Written:

A ∩ B

### Neither

Belongs to neither group.

This region lies outside both circles.

## Connection to Two-Way Tables

The same information can often be represented using either:

- a Venn diagram
- a two-way frequency table

Example categories:

| | Tea | No Tea |
|---|---|---|
| Coffee | Both | Coffee only |
| No Coffee | Tea only | Neither |
