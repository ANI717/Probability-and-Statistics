# Categorical vs Quantitative Data

Variables are commonly divided into two types:

1. **Categorical**
2. **Quantitative**

## Categorical Variable

A **categorical variable** places individuals into groups or categories.

Examples:

- Eye color
- Country
- Blood type
- Car brand
- Yes / No

Example:

`Color = Red`

"Red" identifies a category.

## Quantitative Variable

A **quantitative variable** represents a numerical measurement or quantity.

Examples:

- Age
- Height
- Weight
- Income
- Temperature

Example:

`Height = 178 cm`

The number represents an actual measurable quantity.

## Important

A variable containing numbers is **not automatically quantitative**.

Example:

`ZIP Code = 19104`

Although it uses numbers, a ZIP code is an identifier/category, not a measurable quantity.

## Quick Test

Ask:

> Does arithmetic on this value have meaningful interpretation?

If yes → usually **quantitative**.

If the value mainly identifies a group → usually **categorical**.
